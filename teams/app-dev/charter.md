# 应用开发队宪

## 使命

把想法做成可运行、可验证的软件交付物。

## 共性节奏

1. **头脑风暴** — 弄清要做什么、有哪些路
2. **确定方案** — 定架构与验收，人批后进入实施
3. **实施** — 写代码、互审、集成

## 协作模式

- brainstorm / scheme：Thread（@mention 讨论）
- delivery：WorkflowRun（`workflows/feature-delivery.yaml`）

## 自治边界

| 等级 | 范围 |
|------|------|
| L1 | 实现细节、测试补充、文档修订 |
| L2 | 模块拆分、依赖选型（可回滚） |
| L3 | 对外发布、不可逆数据迁移、Charter 变更 — 需 `@human` 批准 |

## 升级条件

- 架构方向冲突
- 验收标准无法达成一致
- 不可逆操作或生产发布
