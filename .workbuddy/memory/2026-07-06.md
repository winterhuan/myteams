# 2026-07-06 工作日志

## myteams v2.0 设计方案（主理人齐活林协调，多 agent 协作产出）

### 任务
用户要求基于 docs 下所有文档 + 外部调研，重新设计 myteams agent teams 平台方案。核心诉求：多专业团队（短剧/小说/应用开发）各干各的、各队自定义工作方式、头脑风暴→定方案→实施→验证→自动优化、团队长期存在可自主进化、看板掌握进展、**用户能看懂能理解**。先给出设计方案。

### 协作流程（标准 SOP 部分工作流）
1. 主理人创建团队 `software-myteams-design`
2. 并行启动 4 个探索 agent（后台）：
   - doc-explorer：通读 16 份参考项目分析 + 横向对比矩阵，提炼洞察
   - web-explorer：WebSearch/WebFetch 调研 2025-2026 外部最新方案（13 个新项目）
   - ux-reviewer：诊断 v1.2 方案的可理解性
   - evo-explorer：深挖进化机制与看板机制落地
3. 4 份探索报告写入 `docs/exploration/01-04`
4. 主理人综合 4 份报告 + v1.2 + 横向对比矩阵，形成设计纲领
5. 产品经理许清楚基于纲领产出 v2.0 方案（1576 行，12 章）→ `docs/myteams-方案-v2.md`
6. 架构师高见远做技术可行性 review（YES WITH CONDITIONS，4 个 P0）
7. 产品经理修订 4 个 P0 + W6 拆分，主理人验证通过

### 关键设计决策
- **保留 v1.2 架构骨架**（Team 一等对象、两层结构、Briefing 进化、Harness 中立、双模式协作）
- **体验层重构**：5 核心概念（团队/作品/看板/团队笔记本/待你拍板）+ 全中文化命名 + 三套官方模板 + 跨团队总览首页 + 阶段降级为进度条
- **机制层补强**：进化 T1/T2/T3 三档触发 + 信号阈值晋升 + 条件注入三层模型 + Curator 衰减 + meta-charter 双层校验；看板补 eta/last_touched/next_action + 健康度算法 + 活态摘要卡；新增意图路由 + Decision Packet + 工作分解可见
- **差异化发挥**：团队角色卡（Team as a Character，最大差异化）+ 工作分解可见可干预 + 决策叙事 + 跨团队农场视图
- **实施路线调整**：跨团队总览从 Phase 3 提前到 Phase 1；Phase 1 同时验证应用开发队 + 短剧队；W6 进化闭环拆分为两周

### 经验沉淀
- 多 agent 并行探索 + 主理人综合判断 + 产品经理产出 + 架构师 review 的 SOP 流程有效
- 探索 agent 用 general-purpose（有 WebSearch/WebFetch/Write），产出质量高
- "Never delegate understanding"——主理人必须自己读报告全文形成判断，再给产品经理精确指令
- 架构师 review 的 P0/P1/P2 分级 + 任务分解很有价值，避免了实施阶段的返工
